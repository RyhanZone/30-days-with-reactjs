# 📝 Todo App

A clean and modern Todo App built with React.js.  
This project is part of my **30 Days With React Challenge** 🚀

---

## 📸 Project Screenshot

![Todo App Screenshot](./Screenshot%202026-05-23%20163520.png)

---

# ✨ Features

✅ Add new tasks  
✅ Edit existing tasks  
✅ Delete tasks  
✅ Mark tasks as completed  
✅ Clean dark UI design  
✅ Responsive layout  
✅ Component-based structure  
✅ Real-time state updates with React

---

# 🛠️ Technologies Used

- React.js
- JavaScript
- CSS
- Vite

---

# 📚 What I Learned From This Project

While building this project, I learned and practiced:

- React component structure
- useState hook
- Handling form inputs
- Rendering lists with `.map()`
- Passing props between components
- Event handling in React
- Conditional rendering
- Updating state dynamically
- Basic project structuring in React

---

# 🎯 Project Goal

The goal of this project was to improve my React.js skills by building a real project instead of only watching tutorials.

This project is also part of my journey to become better at frontend development and build consistency through daily practice.
