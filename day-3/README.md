# 🔢 Counter App

A modern and interactive Counter App built with React.js.

This project is part of my **30 Days With React Challenge** 🚀

# ✨ Features

✅ Increase counter value

✅ Decrease counter value

✅ Reset counter functionality

✅ Custom Min & Max limit settings

✅ Progress bar visualization

✅ Keyboard support (Arrow Up / Arrow Down)

✅ Dark Mode UI

✅ Real-time state updates

✅ Responsive layout

✅ Component-based architecture

---

# 🛠️ Technologies Used

* React.js
* JavaScript
* Tailwind CSS
* Vite
